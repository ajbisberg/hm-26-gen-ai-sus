# Generative AI & Sustainability S26
## HM + CalPoly
Instructor: Alex Bisberg

Student materials for **Generative AI & Sustainability: Rethinking the Future**, Munich Summer School 2026.

This repository contains the materials you will use during class. Files may be updated as the course progresses, so check back for the latest versions.

## Course materials

- [Slides](slides/) — lecture and workshop slides, organized by class date.
- [Assignments](assignments/) — admission tickets, activities, worksheets, and project guides.
- [Handouts](handouts/) — reading guides and other supporting materials.
- [Scripts](scripts/) — starter code for in-class labs.

## Using the files

Slide decks are provided as PDFs. Assignments and handouts are Markdown files that you can read directly on GitHub.

Clone the full repo and pull for updates. To save an individual file locally, open it and use GitHub's download button. You can also download the entire repository as a ZIP from the repository's **Code** menu.

Bring the requested assignments or notes to class in the format specified by your instructor.
